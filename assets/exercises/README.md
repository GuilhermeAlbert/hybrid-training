# Exercise Illustration Library

This directory contains AI-generated visual references for the exercises used in the training sheets. Each image is a three-frame sequence intended to help identify the setup and general movement path.

## Generation style

The images were generated with the built-in image generation tool using this shared direction:

> Create a clean three-panel instructional illustration showing the start, transition, and finish of the exercise. Use the same generic adult athlete in each panel, a bright neutral gym background, muted blue and charcoal clothing, anatomically coherent positions, consistent equipment, and minimal arrows. Include no text, labels, logos, or watermark.

Exercise-specific prompts added equipment, camera angle, joint position, and safe movement cues. The front lat pulldown received an additional correction prompt to keep the bar visibly in front of the head and descending toward the upper chest.

## Limitations

Generated images can contain anatomical or equipment inaccuracies. Use the written cue in the matching training sheet as the primary reference and ask a qualified coach when technique is uncertain.
